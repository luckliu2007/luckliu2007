## 怎么保持更新

- [content-radar](https://github.com/luckliu2007/content-radar)：每天扫描各仓库引用的 GitHub 项目，标记归档、改名、停更，并按主题发现新的优质项目。
- 每天审核雷达结果后收录（每个仓库每天最多 3 条），CI 通过后合并；每周一按各仓库 `ROADMAP.md` 的“待补强方向”检索一手资料。
- 收录原则：官方和权威来源优先，只写核实过的事实，宁缺毋滥。
